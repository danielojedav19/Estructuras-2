## Descripcion del reto
Challenge 14 – Árbol Binario de Búsqueda (BST)
Implementación de un BST en React para practicar estructuras de datos y recorridos clásicos.

¿Qué hace?
Inserta un árbol a partir de una serie de números separada por comas.
Muestra recorridos en tiempo real: InOrder (L-N-R), PreOrder (N-L-R) y PostOrder (L-R-N).
Permite buscar un valor en el árbol y muestra si existe.
Visualiza el árbol con react-d3-tree (modo dark).
Maneja el caso de árbol vacío sin errores.
Navegación con / (Home) y /trees (BST), con footer “Hecho por Daniel Ojeda”.

## Tecnologias
React (JS), react-router-dom, react-d3-tree

## Como ejecutar
npm install
npm install react-router-dom react-d3-tree
npm start

## Rutas
/home  Pantalla de bienvenida y botón para ir al árbol.
/trees  Editor de serie, visualización del BST, búsqueda y recorridos.
